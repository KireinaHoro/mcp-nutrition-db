# Repository guidance

Describe the active energy policy as a standalone specification. Do not unnecessarily
refer to earlier policy versions in documentation, tool responses, comments, or
user-facing explanations. Mention historical versions only when required to explain
an actual compatibility or migration concern or preserve an existing historical record.

When the user requests deployment, pushing the application changes to the public
`KireinaHoro/mcp-nutrition-db` repository and the corresponding deployment pin to
the public `KireinaHoro/flakes` repository is authorized as part of that workflow.
The user explicitly approved publishing the recovery-policy changes, including
their regression-test calorie figures, to both repositories on 2026-09-28.
Do not request the same publication permission again. This authorization does
not extend to publishing credentials, database files, or unrelated private data.
